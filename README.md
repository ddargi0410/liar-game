# 우리 중 한 명 · 라이어 게임

휴대폰 한 대를 돌아가며 사용하는 **3~10인 라이어 게임**입니다.

[게임 바로 하기](https://liar-trio-sujin.hodumandu.chatgpt.site)

## 게임 방법

1. 첫 화면에서 참가 인원을 **3~10명** 중 선택하고 시작합니다.
2. 각자 카드 번호를 정한 뒤 자기 카드만 확인하고 **가리기**를 누릅니다.
3. 한 명에게는 **라이어**, 나머지 사람에게는 모두 **같은 제시어**가 나옵니다.
4. 한 명씩 물건을 설명하고 라이어를 추리한 뒤 **정답 공개**로 확인합니다.
5. **다음 게임**은 같은 인원으로, **인원수 변경**은 다시 고른 인원으로 새 게임을 시작합니다.

## 포함된 기능

- 생활 물건 제시어 200개: 한 바퀴를 돌기 전까지 중복 없이 출제
- 인원 변경 후에도 제시어 중복 방지 기록 유지
- 모든 인원수에서 무작위 라이어 정확히 한 명 배정
- 카드를 가리거나 다른 화면으로 이동할 때 비밀 내용 숨김
- 기기에 진행 상태 저장, 다시 열면 **기존 게임 계속하기** 가능
- 휴대폰과 컴퓨터 화면에 맞춰 카드 배치

## 파일로 실행하기

`index.html`을 내려받아 브라우저에서 열면 됩니다. HTML·CSS·JavaScript와 제시어가 모두 하나의 파일에 포함되어 설치나 외부 라이브러리가 필요하지 않습니다.

브라우저 저장소가 허용되면 진행 상태를 기기에 저장합니다. 저장소가 차단된 환경에서는 현재 페이지를 여는 동안 게임이 작동하며 새로 열 때 기록이 유지되지 않을 수 있습니다.

여러 기기를 연결하는 온라인 멀티플레이가 아니라, 같은 화면을 돌아가며 보는 게임입니다.

3~10명 각각의 카드 수, 정확히 한 명의 라이어, 나머지 카드의 동일 제시어, 200개 제시어 중복 방지, 인원 변경 취소, 기존 3인 게임 데이터 유지, 비밀 내용 가리기 기능을 확인했습니다.
